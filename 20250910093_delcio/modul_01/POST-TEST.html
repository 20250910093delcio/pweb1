FAKULTAS ILMU KOMPUTER

Profil Seluruh Program Studi

1. Program Studi Teknik Informatika

Program Studi Teknik Informatika mempelajari perancangan, pengembangan, dan pengelolaan perangkat lunak serta teknologi informasi. Materi yang dipelajari meliputi pemrograman, algoritma, basis data, jaringan komputer, keamanan siber, dan kecerdasan buatan. Lulusannya dapat bekerja sebagai pengembang perangkat lunak, analis sistem, atau administrator jaringan.

2. Program Studi Sistem Informasi

Program Studi Sistem Informasi menggabungkan teknologi informasi dengan ilmu manajemen dan bisnis. Mahasiswa mempelajari cara merancang dan menerapkan sistem informasi untuk membantu organisasi bekerja lebih efektif. Lulusannya dapat menjadi analis sistem, manajer proyek teknologi, atau konsultan sistem informasi.

3. Program Studi Desain Komunikasi Visual (DKV)

Program Studi DKV mempelajari cara menyampaikan informasi melalui tampilan visual yang menarik dan mudah dipahami. Materinya meliputi desain grafis, tipografi, fotografi, desain web, dan animasi. Lulusannya dapat bekerja sebagai desainer grafis, desainer web, atau ilustrator.

4. Program Studi Teknik Sipil

Program Studi Teknik Sipil mempelajari perencanaan, pembangunan, dan pemeliharaan infrastruktur seperti jalan, jembatan, dan gedung. Materinya meliputi struktur bangunan, mekanika tanah, dan manajemen proyek konstruksi. Lulusannya dapat bekerja sebagai insinyur sipil, konsultan, atau pengawas proyek.
